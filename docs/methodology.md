# 訓練方法論

> v1.0（2026-07-27）。已整合兩份研究：訓練方法論實證（Um_nik/Yoneda/Errichto/Galen + 刻意練習文獻）、台灣 IOI 選拔賽制查核（tpmso.org/toi 官方公告）。

對象：一名學生，基礎 C++ 語法起步，目標 IOI 2029 金牌（2027 診斷、2028 拿牌、2029 衝金）。
上限 12h/天，不設下限。深度解題每日 ≤6–8h，其餘為低認知負荷活動。

## 三階段學習模型（每單元三階，階段遞增認知負荷）

每個單元分三階段，嚴格遞進，不得跳階：

### Phase 1：學習（Encoding）
- **目標**：建立「記」——完整的語法理解 + 肌肉記憶
- **流程**：家教展示語法模板（最小範例）→ 學生在 vim 中跟著打一遍 → 編譯執行看輸出 → 確認理解（evidence 檢核）
- **提供要素**：語法模板、vim 練習指引、跟打檔案（work/templates/）
- **心法**：這是編碼階段，不是回憶階段。不打就是沒學。一次一行、確認理解再前進。
- **出口條件**：能默寫語法骨架（不看參考）

### Phase 2：練習（Deliberate Practice）
- **目標**：刻意回想剛學的語法，透過 desirable difficulty 鞏固
- **流程**：家教指派檢核題 → 不再提供語法展示 → 學生靠自己回想語法解題
- **提供要素**：僅題目連結（zj/a001、cses/1068...）
- **心法**：回想本身就是學習。卡住是好事——卡完再看語法等於複習兩次。
- **模式**：速練 mode=speed（3 分鐘提示閘），目標一次寫對不回頭
- **出口條件**：檢核題全 AC

### Phase 3：考試（Forced Recall）
- **目標**：空白環境、全新題目、強行回憶，將工作記憶固化為長期記憶
- **流程**：獨立解題 → 60 分鐘提示閘 → 完全不給語法參考
- **提供要素**：僅題目（無語法、無模板、無教學）
- **出口條件**：AC 或完成完整思路

### 記憶兩階段理論
1. **記（Encoding）**：有語法展示、有講解、有肌肉記憶（對應 Phase 1）
2. **憶（Retrieval）**：空白環境、強行回想（對應 Phase 2 & 3）

這不是現代教育體系的「聽過=會了」，而是認知科學的「產出=學習」。

## 知識圖譜（前置條件 DAG）

每個單元明訂 `prerequisites`（前置單元）與 `prerequisite_topics`（前置知識點），設計參考 os-taxonomy（github.com/withmarbleapp/os-taxonomy）的 1,590 個微節點 + 3,221 條前置邊結構。

學習路徑是圖不是線：前置條件未滿足時，algo.today 會顯示「前置未完成」，引導學生先補前置再前進。不讓學生無意義摸索。

## 核心迴路（每題五步，全程留痕於 log/）

1. **選題**：難度 = 當前 rating +200~400，目標解出率 30–50%（專家共識：Ericsson 刻意練習「略超當前能力」＋SuperJ6/Um_nik/Errichto 實務收斂點），按 `algo stats` 弱點熱圖加權
2. **限時思考**：無進展才開提示階梯，逐級且每級之間再想 15 分鐘。卡題時限隨程度升級：入門 30 分鐘 → 1600+ 後 60 分鐘 → 2100+ 後 90 分鐘（Um_nik 主張想數小時、Yoneda/Errichto 主張有界時限；三年期限下取有界遞增的折衷）：
   - L1 方向（「這是圖論建模題」）
   - L2 關鍵觀察（「答案具單調性」）
   - L3 引理/核心步驟
   - L4 完整題解 → 必須從空白重新實作
3. **實作自測**：動筆前寫複雜度預算；邊界清單過一遍；懷疑時對拍（暴力比對 + 隨機/極端數據）
4. **事後分析**：`algo add`——主因分類（見 error-taxonomy.md）、費曼摘要、線索卡
5. **間隔重複**：`algo due` 排程 7/30/90 天，空白重推解法（回想，不是重讀）

## 每日結構（範本，非硬性）

| 時段 | 時長 | 內容 |
|---|---|---|
| 深度解題 | 4–5h | 2–3 題核心迴路 |
| 補洞/upsolve | 1.5–2h | 昨日未解題、提示後重做、K 類知識缺口教學迴路 |
| 識別訓練 | 0.5h | 10 題只看題面，5 分鐘口述方向（`algo rec`） |
| 速度訓練 | 0.5–1h | 已知解法題限時實作，練無 bug 吞吐量 |
| 複習 | 0.5–1h | `algo due` 到期題空白重推 |
| 理論輸入 | 0.5–1h | 新主題學習、題解閱讀、總結撰寫 |

每週一次 virtual contest + 完整複盤（時間線重排：「應該的分配」）。
每週日寫週報：錯誤分佈、弱點熱圖、下週選題方向——這是 LLM 診斷的輸入。

**塊狀→交錯原則**（Rohrer 等交錯學習研究 + USACO Guide 實務）：新主題先塊狀集中練（如連續 10–15 題線段樹）建立組塊，之後只透過混合題單和 virtual 交錯出現——因為賽場上題目不帶標籤。識別訓練就是交錯的極端形式。

## LLM 的四個角色與紅線

1. 提示階梯執行者——**紅線：未到時限不得給提示；一次只給一級**
2. 變體題生成——同型變體 2 題鞏固 K 類缺口
3. 解法陳述審查——學生寫費曼摘要，LLM 抓理解漏洞、追問
4. 日誌診斷——讀 attempts.jsonl 產週報與選題建議

## 三年分期

| 階段 | 時間 | 出口條件 | 主食 |
|---|---|---|---|
| P0 起步 | 2026.08–09 | STL 熟練、會對拍、CSES 入門段完成 | CSES、CF div3/4 |
| P1 覆蓋 | 2026.10–2027.04 | CF 1600；CSES ~200 題；經典主題一輪 | CSES、CF、AtCoder ABC、CP-31 題單 |
| P2 深化 | 2027.05–2028.02 | CF 2100；能競一等獎 → 選訓營 | AtCoder ARC、CF div1/2、USACO Gold/Plat 主題 |
| P3 賽制轉換 | 2028.03–08 | CF 2300+；IOI 2028 目標銀 | oj.uz 歷年 IOI/JOI/CEOI/APIO、5h 模擬 |
| P4 衝金 | 2028.09–2029.08 | 穩定 CF 2400+（GM）實力；IOI 2029 金 | IOI 整套限時、互動/output-only/communication、CMS 全真模擬 |

**Rating ↔ 獎牌對照**（社群統計，中等信度）：銅 ≈ CF 1900–2100、銀 ≈ 2100–2300、**金 ≈ 2400+（GM）**。金牌 = 前 1/12，強年份 2500 也可能落榜——所以 P4 出口是「穩定 2400+」不是「摸到 2400」。

**量的參照**（Yoneda 數據）：~250 題到 1200、GM 路上累計 ~1000+ 題；三年總量預估 2000–3000 題。已記錄的快速軌跡（Yoneda 本人 ~2.5–3 年到 IOI 銀）證明時程激進但有先例；多數金牌是 4–6 年——這就是為什麼反饋迴路品質是唯一的槓桿。

**主題順序**（USACO Guide / CSES 正典）：實作暴力 → 二分+貪心+前綴/雙指針 → **DP（大坎）** → 圖論 → 區間資結 → 樹上技巧 → 數學/字串 → 流/幾何/進階。

### IOI 賽制特化（P3 起）

- **第一小時掃三題撈保底 subtask，再回頭深挖**——3×60 部分分 > 1×100 未完成；每次模擬都複盤 subtask 分配時間線
- 互動題、output-only、communication 題 CF 上沒有，只能靠 oj.uz 歷年題專項drill
- 無罰提交 + 即時回饋（2010 起）→ 對拍器和暴力驗證器要練成反射動作
- 已知失敗模式：後期過度打 CF 追速度——IOI 獎勵深度不獎勵手速，P4 的 CF 只用來維持解題力

### 台灣選拔鏈（已查核 + 教練補充修正）

**能競、APCS、海選三路都通初選；夠強可以逐級跳過**（能競一、二等獎免初選直入一階）。初選本身不難：簡單線段樹、進階圖論、DP、矩陣快速冪、滾動哈希，加上**撈子題分數的能力**。過初選即選訓營。

- **能競線**：11 月區賽 → 全國決賽 → 一、二等獎（約 10 人）**免初選**直入一階
- **初選線（保底，明文接納自學生）**：APCS 實作三級分 → 12–2 月報名 → 3 月初選（上機、限 C++）
- 之後：3 月下旬一階（~37 人）→ 4 月中二階（~12 人）→ 6 月國手 4 名 → 7–8 月 IOI

**今年目標（2026–27 學年）：進選訓營。** 主戰場排序：
1. **10–11 月 APCS 三級分**——初選門票，必拿（第一個外部檢核點）
2. **11 月能競**——全力打，二等獎即免初選；當加速器不當獨木橋
3. **2027-03 初選**——主戰場，考點明確（見上），專項特化即可

因此 P0/P1 前壓：前 4 個月主食 = APCS/能競風格（實作 + 基礎算法，恰為 CSES 入門段）；12–2 月加入初選考點特化（線段樹、DP、圖論、矩陣快速冪、滾動哈希 + 子題策略）。

**年度節奏**：APCS 一年三場（約 1、6、10–11 月）；11 月能競；3–4 月選訓營。2027/2028/2029 各有多輪入營機會。

**校正線**：2027-03 未過初選 → 全力 6 月 APCS 提級分 + 2027-11 能競，2028-03 初選再戰；CF 里程碑照舊（2027-04 < 1500 即重估節奏）。

## 平行線

- **數學**：每週 3–4h——組合計數、不變量、證明寫作。不需要 IMO 級數學。
- **模板庫**：每個新演算法 = 一份自己手寫、註記觸發線索的模板；速度訓練用它默寫。
- **體能/賽感**：P3 起每月一次 5 小時全真模擬（禁網、紙筆、CMS 介面），練部分分策略與體力分配。

## 反模式（明令禁止)

- 看題解不重新實作
- 連續刷低於 rating+100 的舒適區題
- 一天超過 12 小時
- 提示未到時限就開
- 只記 AC 不記失敗——失敗才是日誌的主要價值
